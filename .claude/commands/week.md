直近7日（今日を含む）の振り返りをしてください。

## 手順
1. `TZ=Asia/Tokyo date +%F` で今日の日付を確認し、7日間の範囲を決める。
2. 体重グラフを作る：`python3 scripts/plot_weight.py --days 30`
   - 出力された `data/weight.png` を読んで傾向を確認する。記録が少なくてグラフが作れない場合はスキップしてよい。
3. 次を読む。
   - `data/weight.csv`、`data/exercise.csv`、範囲内の `data/meals/*.md`、`data/goal.md`
4. 集計する。
   - **体重**：週の最初と最後の記録、週平均、先週平均との差（先週の記録があれば）。月1〜2kgペースと比べてどうか。
   - **運動**：ウォーキング回数と合計km（目標：週4〜5回・約5km）、ランニング回数、スクワット回数。
   - **ルール達成率**：6ルールそれぞれの ○ の数 ÷ 記録のある日数。△ は0.5として数える。「ー」は分母に入れない。
5. 次の形で**短く**返す。

```
📊 10/24〜10/30 のまとめ
⚖️ 73.0 → 72.4kg（週平均 72.7kg、先週比 −0.4kg）ペース順調👍
🚶 ウォーキング 4回・19.5km ／ 🏃 ランニング 1回 ／ 🦵 スクワット 0回

✅ ルール達成率
- 夕食は腹七分目 5/6
- 野菜→おかず→ご飯 3/6
- …

👍 今週よかったこと：（1つ）
🎯 来週の重点：（1つだけ。具体的で、子育て中でも続けやすい行動）
```

グラフは `data/weight.png` に保存したことを1行で伝える。
