---
description: 話した内容（体重・食事・運動など）を解析して data/ に記録する
argument-hint: 例）体重72.4、昼はそば、5km歩いた
allowed-tools: Read, Write, Edit, Glob, Bash(TZ=Asia/Tokyo date:*), Bash(date:*)
---

次の内容を記録してください。

> $ARGUMENTS

## 手順
1. `TZ=Asia/Tokyo date +%F` で今日の日付を確認する。「昨日」「おととい」「10/28」など日付の指定があればその日にする。
2. 内容を次の種類に分けて、該当ファイルに追記する。
   - **体重**（例：「体重72.4」「72.4kg」）→ `data/weight.csv` に `date,weight_kg,memo` で1行。同じ日付の行があれば置き換える。
   - **運動**（例：「5km歩いた」「30分走った」「スクワット20回」）→ `data/exercise.csv` に `date,type,distance_km,minutes,memo` で1行。
     - type は `walking` / `running` / `squat` / `other`。回数などはmemoへ。分からない値は空欄。
   - **食事**（例：「昼はそば」「間食にバナナ」）→ `data/meals/YYYY-MM-DD.md`。
     - ファイルがなければ `data/meals/_template.md` をコピーして作り、見出しの日付と曜日を埋める。
     - 朝・昼・夕・間食の該当する見出しの下に `- 料理名` を追記する（空の `- ` 行は置き換える）。時間帯が分からなければ今の時刻から判断する。
   - **ルールに関わる話**（例：「21時以降は食べてない」「ゆで卵食べた」「夕食は控えめ」「野菜から食べた」）→ その日のファイルの「ルールチェック」表を ○ / △ / × で更新する。
     - 食事の内容から明らかなものだけ更新してよい（例：納豆を食べた → 「納豆・豆腐・バナナ」を ○）。推測が必要なものは「ー」のままにする。
   - **その他**（体調・気分など）→ その日の食事ファイルの「メモ」へ。
3. CSVのメモにカンマが入る場合は `"` で囲む。既存の行の並び（日付順）を崩さない。
4. 何をどこに書いたかを、次の形で**短く**報告する。

```
📝 記録しました（10/30）
⚖️ 体重 72.4kg（前回比 −0.3）
🍽 昼：そば
🚶 ウォーキング 5km
```

最後に、前向きなひとことを1行だけ添える（例：「歩けた日は記録が楽しくなりますね👍」）。体重は前回の記録があれば差を出す。
解釈に迷う内容は記録せず、何が分からなかったかを1つだけ質問する。
