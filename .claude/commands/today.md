今日の振り返りをしてください。$ARGUMENTS に日付があればその日を対象にします。

## 手順
1. `TZ=Asia/Tokyo date +%F` で今日の日付を確認する。
2. 次を読む。
   - `data/weight.csv`（対象日と、その前の記録）
   - `data/exercise.csv`（対象日）
   - `data/meals/対象日.md`
   - `data/goal.md`（目標が書いてあれば）
3. CLAUDE.md の食事ルール6つを ○ / △ / × / ー で判定する。
   - 食事ファイルの「ルールチェック」の値を優先する。「ー」のものは、食事内容から明らかに判断できる場合だけ判定し、それ以外は「ー」のまま。
4. 次の形で**短く**返す。

```
📅 10/30（木）のふりかえり
⚖️ 72.4kg（前回比 −0.3）  🚶 ウォーキング 5km

| ルール | 結果 |
|---|---|
| 夕食は腹七分目 | ○ |
| 野菜→おかず→ご飯 | △ |
| 21時以降は食べない | ○ |
| 帰宅前にゆで卵 | × |
| 減塩 | ○ |
| 納豆・豆腐・バナナ | ○ |

👍 よかったこと：（1つ）
🌱 明日へのひとこと：（すぐできる具体的な行動を1つ）
```

- 記録がほとんどない日は、責めずに「/log で一言だけでも残しましょう」と案内する。
- アドバイスは子育て中・平日日勤でも無理なくできる内容にする。
